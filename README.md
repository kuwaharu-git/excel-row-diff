# excel-row-diff

二つの Excel ファイルを比較し、同名シート同士の差分（片方にしか無い行）を抽出するツールです。

すべてのシートを自動検出し、以下を実行します：
- 両方に存在するシート → 行ごとの差分を抽出
- 片方にしか存在しないシート → そのシート丸ごと差分扱い
- 出力ファイルはシートごとに分割（SheetName_only1 など）
- summary シートで差分の件数を一覧表示

## ✨ 主な機能

- **全シートを自動比較**: 両方のファイルのすべてのシートを自動検出
- **同名シート同士の差分を行単位で抽出**: 各シートの行を比較し、片方にしか存在しない行を抽出
- **片方にしか存在しないシートにも対応**: シート自体が片方のファイルにしかない場合も検出
- **出力ファイルにシート名を引き継いでわかりやすく保存**: 
  - `SheetName_only1`: ファイル1にのみ存在する行
  - `SheetName_only2`: ファイル2にのみ存在する行
- **分析しやすいサマリシート付き**: 各シートの差分件数を一覧表示

## 📋 必要要件

- Python 3.8 以上
- openpyxl ライブラリ

## 🚀 インストール

### 方法1: 直接実行

```bash
# 依存関係をインストール
pip install openpyxl

# スクリプトを実行
python excel_row_diff.py file1.xlsx file2.xlsx
```

### 方法2: パッケージとしてインストール

```bash
# リポジトリをクローン
git clone https://github.com/kuwaharu-git/excel-row-diff.git
cd excel-row-diff

# パッケージをインストール
pip install -e .

# コマンドとして実行
excel-row-diff file1.xlsx file2.xlsx
```

## 💡 使い方

### 基本的な使い方

```bash
python excel_row_diff.py file1.xlsx file2.xlsx
```

出力ファイル `diff_result.xlsx` が作成されます。

### 出力ファイル名を指定

```bash
python excel_row_diff.py file1.xlsx file2.xlsx -o output.xlsx
```

### ヘルプを表示

```bash
python excel_row_diff.py --help
```

## 📊 出力形式

出力Excelファイルには以下のシートが含まれます：

1. **summary**: 差分の概要
   - シート名
   - 状態（両方に存在、ファイル1のみ、ファイル2のみ）
   - ファイル1のみの行数
   - ファイル2のみの行数
   - 総差分数

2. **SheetName_only1**: ファイル1にのみ存在する行
   - 元のシートのヘッダー行を含む
   - ファイル2には存在しない行データ

3. **SheetName_only2**: ファイル2にのみ存在する行
   - 元のシートのヘッダー行を含む
   - ファイル1には存在しない行データ

## 🔍 比較の仕組み

1. **シートの検出**:
   - 両方のファイルからすべてのシート名を取得
   - 共通シート、ファイル1のみ、ファイル2のみに分類

2. **行の比較**:
   - 各シートの1行目はヘッダーとして扱う
   - 2行目以降のデータを行単位で比較
   - 空行は自動的にスキップ
   - 行全体の値をタプルとして比較（完全一致のみ同じ行と判定）

3. **差分の抽出**:
   - ファイル1にのみ存在する行 = rows1 - rows2
   - ファイル2にのみ存在する行 = rows2 - rows1

4. **出力**:
   - 差分がある場合のみシートを作成
   - シート名が長い場合や特殊文字が含まれる場合は自動的に調整

## 📝 注意事項

- Excelファイルは `.xlsx` 形式を推奨（`.xls` は非対応）
- 各シートの1行目はヘッダーとして扱われます
- 行の比較は完全一致で行われます（部分一致や類似判定は行いません）
- セルの書式（色、フォントなど）は比較対象外です
- 数式は計算結果の値で比較されます（`data_only=True`で読み込み）
